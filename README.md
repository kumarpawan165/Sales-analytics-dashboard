# Sales-analytics-dashboard
The sales analytics dashboard is a Data analytics project developed using Python, SQL, and power BI.

# The project analyzes:
• Sales trends
• Revenue growth 
• Customer behavior 
• Product performance 
• Regional sales distribution 

# Technologies used:
•Python 
•pandas 
•numpy 
•matplotlib 
•mysql
•power BI


# Features :
 •Monthly sales analysis 
 •Revenue Tracking 
 •Product performance analysis 
 •Customer insights 
 •Region-wise Reports
 •Profit analysis

 3 Data storage using MySQL

 5 Dashboard Creation
 6 Business Insights Generation
